# 🖤 Night Crowley - Dark Gothic Store

E-commerce com estética gótica e alternativa, totalmente responsivo (Mobile & Desktop), sem dependências externas.

## 🔮 Funcionalidades
- **Layout Responsivo**: Design mobile-first estendido para desktop com grelha de 4 colunas.
- **Catálogo Dinâmico**: Filtros por Categoria, Tema e Marca, além de barra de pesquisa.
- **Perfil do Utilizador**: Área com histórico de pedidos e Lista de Desejos (*Wishlist*).
- **Estética Temática**: Cores escuras (#0A0A0A, #8B0000, #D43838) e tipografia *Cinzel*.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Media Queries & Flexbox/Grid)
- JavaScript Vanilla
- Font Awesome & Google Fonts
